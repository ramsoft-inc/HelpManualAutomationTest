# OmegaAI Keyboard Navigation

This section provides a detailed overview of keyboard navigation behaviour within **OmegaAI**. It is designed to assist radiologists and clinicians in efficiently navigating and editing reports using keyboard shortcuts.

## Keyboard Navigation: Behaviour in document viewer

### Arrow Keys

|**Key Action**|**OmegaAI Behaviour**|
| :- | :- |
|Left / Right Arrow|Moves the cursor one letter left/right. If no more words, moves to the previous/next field. |
|Up / Down Arrow|Navigates between fields vertically. Inside multiline fields, moves line by line.|

### Tab Navigation

|**Key Combination**|**OmegaAI Behaviour**|
| :- | :- |
|Tab|<p>Used for indentation or autocompletion based on context.</p><p>Moves between the fields when the cursor is inside the fields</p>|
|Shift + Tab|` `When the cursor is inside the field, it moves between the fields. Also selects text in the current field.|

### Page Navigation

|**Key Combination**|**OmegaAI Behaviour**|
| :- | :- |
|Page Up / Page Down|Scrolls to the top or bottom of the page.|
|Home / End|Home → Moves to start of line. End → Moves to the end of the line|
|Ctrl + Home / End|Ctrl + Home → Go to top of document. Ctrl + End → Go to bottom of document|

### Text Editing

|**Key Combination**|**Function**|
| :- | :- |
|Ctrl + Z|Undo last change|
|Ctrl + Y|Redo the last undone action|
|Ctrl + C / V / X|Copy / Paste / Cut|
|Ctrl + B|Bold|
|Ctrl + I|Italics|
|Ctrl + U|Underline|
|Ctrl + F|Search|
|Right-click on the misspelt word|Displays spell check suggestions via browser context menu|
